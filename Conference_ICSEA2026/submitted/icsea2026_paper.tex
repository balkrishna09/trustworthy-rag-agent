\begin{abstract}
Retrieval-Augmented Generation (RAG) grounds large language model (LLM) outputs in external knowledge, but RAG systems usually trust whatever they retrieve, creating a \emph{Security-Reliability Gap}: high semantic relevance does not guarantee factual truth. Adversaries exploit this through \emph{knowledge poisoning}, inserting malicious documents to cause targeted misinformation. We propose an \emph{Evaluation Agent}, middleware that combines Natural Language Inference (NLI) factual verification, a five-signal poison detector with relevance-weighted aggregation, and a \emph{Trust Index} $T = 0.4\,F + 0.35\,C + 0.25\,(1-P)$ with a non-linear dampener for high-contamination contexts. On TruthfulQA with Llama~3.3~70B it reaches 91\% accuracy and 100\% precision (+7 points over a naive always-trust baseline), with 100\% recall on instruction injection, while entity-swap and subtle in-place edits remain hard (few surface signals). Across three LLMs, the results show that the Trust Index depends on the generator. Generation style matters more than model size: a 7B model reaches 87\% accuracy, while a 35B model reaches 69\% (both at the default $\tau{=}0.5$, $K{=}5$, mixed TruthfulQA) because its hedged outputs cause false positives. The Trust Index remains discriminative for all models, with ROC-AUC from 0.73 to 0.81, and per-LLM threshold calibration restores baseline-competitive accuracy. Results are stable across repeated runs ($90.6{\pm}0.5\%$ over five runs), and increasing retrieval depth from $K{=}3$ to $K{=}5$ did not change the main metrics in the mixed TruthfulQA setting. A weaker FEVER result indicates that cross-dataset generalization requires dataset- and domain-specific calibration. In a software-engineering use case, a secure-coding assistant over OWASP/CWE guidance, the agent reliably blocks \emph{instruction-injection} of unsafe advice (F1 92\%), while contradiction, subtle weakening, and the mixed setting remain hard. Throughout, the agent measures \emph{detection} of poisoned context before generation, not whether the LLM ultimately adopts the injected misinformation. We release the proposed approach, attack generator, and experimental artifacts\footnote{\url{https://github.com/GPT-Laboratory/TrustworthyRAG}}.
\end{abstract}
