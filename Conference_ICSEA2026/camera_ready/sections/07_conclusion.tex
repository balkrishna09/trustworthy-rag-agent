\section{Conclusion and Future Work}
\label{sec:conclusion}
%==============================================================================

We presented an Evaluation Agent that adds a trust layer to RAG by combining NLI-based factual verification, multi-signal poison detection, and a Trust Index with a non-linear dampener. The agent detects clear poisoning well, including 100\% recall for instruction injection and 100\% precision on TruthfulQA, and the secure-coding use case shows that it can help block injected unsafe advice in the SDLC. The results also show important boundaries: in-place edits are harder to detect, NLI-based trust scoring depends on the LLM used for generation, and the FEVER result shows that dataset-specific calibration is important for generalization. Future work includes evaluating the agent against stronger poisoning attacks, calibrating the Trust Index for different LLMs, adding world-knowledge sources\rev{, such as Wikidata,} to address entity-swap attacks, accelerating evaluation with GPUs, and measuring misinformation \emph{adoption}, or attack success rate, not only detection. \rev{Three further directions follow from the reviewers' suggestions. First, end-to-end attack evaluation should measure whether poisoned guidance actually changes generated artifacts, e.g., whether a corrupted secure-coding rule yields vulnerable generated code or altered developer decisions; this requires coupling the agent with code-level security oracles, such as static analyzers, and user studies. Second, evaluation on larger real-world RAG applications with heterogeneous, continuously updated corpora, where calibration data are scarce. Third, jointly optimizing the weights, dampener parameters, and threshold per deployment, extending the perturbation analysis of Section~V-B.} The implementation of the proposed approach, \rev{the attack generator, and the experimental artifacts} are available for reproducibility \cite{repoartifacts}.
